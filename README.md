Продовження лабораторної №2 на тому самому наборі **Diamonds** з тією самою ціллю `price` ($).
Питання: наскільки точно 4C (вага, огранка, колір, чистота) прогнозують ціну нового діаманта і як ціна
пов'язана з вагою за однакової якості.

## Як відтворити (з чистої копії репозиторію)

1. Встановити Python 3.11+ і Quarto (<https://quarto.org/docs/get-started/>).
2. Створити середовище й поставити залежності:
   ```
   python -m venv .venv
   .venv\Scripts\activate          # Windows;  macOS/Linux: source .venv/bin/activate
   pip install -r requirements.txt
   ```
3. Зібрати звіт і слайди (з кореня репозиторію; порядок задано в `_quarto.yml`):
   ```
   quarto render
   ```
   Результат: `report.html` і `slides.html` у корені, а також оновлені `figures/` і `results/`.
   Збирання триває ≈ 30 с. Усі випадкові кроки мають `seed = 42`.

   **Windows, одна команда:** `powershell -ExecutionPolicy Bypass -File .\build.ps1` — скрипт сам знайде
   Quarto і Python (або `.venv`), збере звіт і слайди, зробить `report.ipynb` і відкриє `report.html`.
4. Ноутбук `report.ipynb` (той самий звіт для Jupyter / VS Code, з виконаними клітинками й підставленими
   числами в тексті) робить `python make_notebook.py` після `quarto render`.

> Якщо Quarto бере не той Python, вкажіть його явно: `set QUARTO_PYTHON=.venv\Scripts\python.exe`
> (macOS/Linux: `export QUARTO_PYTHON=.venv/bin/python`).

## Методи коротко

- Очищення як у лаб. №2: дублікати, нульові розміри, рядки з неузгодженим `depth` → 53 748 каменів.
- Поділ 80/20 (`random_state=42`) до підбору моделей; 5-кратна CV на навчальній частині, однакові розбиття.
- Моделі: M0 константа; M1 лінійна в $; M2 log–log (база для гіпотез, ДІ HC3); M3 + сплайн і пороги ваги;
  M4 + взаємодії; M5 градієнтний бустинг (додатково). Основна метрика — MAE, $.
